## 兼容实现、尚未覆盖与后续细节

1. 复杂高级选项的属性页保留原生标签页几何，统一基础控件；尚未逐页重新排版和逐项 GUI 验证。这样能保留既有参数、控件 ID 和事件。后续适合按使用频率逐页处理。
2. Windows 文件选择器保持系统原生行为/主题，应用浅色时系统选择器仍可为深色。第三方 Shell 扩展的自定义 owner-draw 菜单走原生兼容入口，不强行改写其命令。
3. 实际桌面为当前缩放，混合 DPI/多显示器、高对比度和辅助阅读器尚未实机覆盖；140 组布局计算不等同于这些实机测试。
4. 解压原生“大小”命令已实查启用；自动化在不可见边缘拖拽上未获得稳定的尺寸变化，因此窄窗真实拖拽外观仍需人工复核，不能声称这一项已完整 GUI 验收。
5. 本轮未重跑真实 Word 保存、所有归档格式/高级加密组合及真实 ACL 恢复矩阵；事务层和常用引擎组合通过，原相关业务代码未重写。
